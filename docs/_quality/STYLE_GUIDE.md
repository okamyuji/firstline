# 文書スタイルガイド

このガイドは`tools/doclint/main.go`の規則を人が読める形に書き直したものです。規則の正本はdoclintなので、規則を変えるときは両方を同じ変更で直してください。

`cd tools/doclint && go run . ../../docs`で検証します。Critical、High、Mediumが1件でもあれば失敗です。

## 機械で検証する規則

| 規則 | 重大度 | 内容 |
|---|---|---|
| 強調 | High | アスタリスク2つの強調を使いません。アスタリスクを3つ以上並べただけの行（区切り線）は対象外です |
| 文末コロン | Medium | 日本語の文を半角か全角のコロンで終えません。全角の閉じ括弧（`）`、`」`、`』`、`】`、`〉`）や`々`の後のコロンも検出します。半角の`)`と`]`、インラインコード、リンク、URL、英数字の後のコロンは、同じ行のそれより前にひらがな、カタカナ、漢字があるときに検出します。日本語を含まない行は対象外です。コロンの後の行末の空白は、全角空白も含めて無視します |
| 先送り | Critical | `TBD`、`TODO`、`TODOs`、`後で決める`、`未定とする`、`将来検討`を残しません。英字の語は大文字と小文字を区別せずに検出します。`後で決めます`、`未定とします`のような活用も検出します |
| 境界スペース | High | 日本語と英数字の間に半角スペースかタブを入れません。全角の`！`、`？`、`：`、`【`、`】`、`〈`、`〉`の前後も同じです。見出し行（行頭の3つまでの空白に続く1〜6個の`#`と空白）と、箇条書きの見出し語の直後の区切りは対象外です |
| 用語統一 | High | SQLite、Cloudflare、Litestream、PostgreSQL、MySQL、htmxの表記にそろえ、大文字と小文字の違いも検出します。`sqlite3`と`SQLite3`も誤記として検出します。Goは`golang`の誤記だけを検出します。前に英字が続く語と、後ろに英字か数字が続く語（`mysql8`など）は対象外です |
| 閉じない囲み | High | コードブロックの囲みを閉じずに残しません |

箇条書きの見出し語は行頭の記号（`-`、`*`、`+`、`1.`、`1)`）の後の1語です。見出し語の後の区切りは半角スペース1つで、続く空白とタブは境界スペースとして検出します。次の語は見出し語とみなさず、本文として検証します。

- 句読点を含む語
- 助詞（は、が、を、に、で、と、も、の、へ、や）で終わる語
- 英数字と記号だけの語

動詞で終わる語は見出し語とみなされるので、見出し語は日本語の名詞句で書いてください。

インラインコード、コードブロック、URLは引用と識別子として扱い、どの規則の対象にもしません。インラインコードとURLは、記号`#`1つに置き換えて検証します。Markdownのリンクは括弧の中を消し、`]`を残します。前後の語がつながって見えることはなく、直後の`TODO`や後ろのコロンも検出できます。インラインコードは1つか2つのバッククォートで囲んだものです。

コードブロックは3つ以上のバッククォートかチルダで囲んだものです。行頭の字下げは問わないので、箇条書きの中の囲みも認めます。バッククォートの開きの行で、記号の後ろにバッククォートを含むものはインラインコードとみなします。閉じの行は開きと同じ記号を同じ数以上並べ、後ろに空白しか置かない行です。

URLとして扱う範囲はMarkdownのリンクの括弧の中、空白を含まない`<http://…>`か`<https://…>`の山括弧の中、または`http://`か`https://`から空白、ASCII以外の文字、`]`の手前までです。リンクの括弧の中に丸括弧を含むURLは扱いません。URLの末尾のコロンはURLに含めず、本文として扱います。ファイルの先頭のBOMは外してから検証します。

引用（`>`）の中の囲み、2行にまたがるインラインコード、3つ以上のバッククォートで囲んだインラインコードは扱いません。中身を本文として検証するので、文書ではこれらの形を使わないでください。

日本語として判定する文字は、ひらがな（`ぁ`から`ん`）、カタカナ（`ァ`から`ヿ`）、漢字（`一`から`鿿`）と、記号です。境界スペースで日本語とみなす記号は`、。「」『』（）！？：【】〈〉々〆`です。文末コロンの直前で日本語とみなす記号は`）」』】〉々`で、`〆`は含みません。`ゔ`や`ゝ`、互換漢字、全角英数字、ここに挙げていない記号は日本語とみなさず、境界スペースと文末コロンの対象にしません。URLの直後に空白を置かずに続けた英数字はURLの一部として扱うので、URLの後には日本語か空白を置いてください。

## 人が確認する規則

- 文体 文末はです、ます調にし、体言止めを使いません。
- 箇条書き 見出し語は名詞句にし、本文とは半角スペース1つで区切ります。
- 数え方 文書の本数やテストの件数のように、追加のたびに変わる数を書きません。
